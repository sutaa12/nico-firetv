# NicoTV for Fire TV

Fire TV のリモコンで、ニコニコ動画をコメント付きで見るための非公式 Android アプリです。
ランキングや検索から動画を探し、シリーズの連続再生や、端末に保存した位置からの再開ができます。

**開発中のソースコードを公開しています。**
株式会社ドワンゴ、ニコニコ、Amazon が提供・公認するアプリではありません。
ニコニコ側の仕様や端末の違いにより、ログイン・再生などが利用できなくなる場合があります。

## はじめて使う方へ

現時点では、ソースコードから APK（Android アプリのインストール用ファイル）を作り、Fire TV に入れる方法を案内しています。
PC と Android 開発環境が必要です。

1. [ビルドとインストール](docs/BUILDING.md)に沿って、APK を作り、Fire TV に入れます。
2. 起動後は「設定 → データの取得元 → デモ」で操作を試せます。デモ動画の再生にもインターネット接続が必要です。
3. 「ニコニコ」に切り替えて動画を探します。ログインが必要な機能は「設定 → アカウント」から利用します。

## 主な機能

- ランキング、キーワード・タグ検索、動画の詳細表示。
- シリーズ・投稿動画・マイリストからの連続再生。
- 通常コメントと過去コメントの表示、表示量・文字サイズ・透明度の調整、端末内の NG 設定。
- 端末内の視聴履歴、続きから再開、お気に入り。
- 公式ログイン画面を使ったログイン、アカウントの視聴履歴・マイリスト・あとで見るの読込。
- 再生速度、ループ再生、動画によって利用できるシーク用の縮小画像。

これらは実装されている機能です。
実際のニコニコアカウントを使う機能や有料作品について、すべての条件での動作を確認したものではありません。

## 対象と制限

対象は Android ベースの Fire OS を搭載した Fire TV です。
Android 7.1 / API 25 以上をビルド条件にしていますが、全機種での動作を保証するものではありません。
Android APK を実行できない端末は対象外です。

生放送・タイムシフト、DRM 保護作品、コメント投稿、マイリスト編集、フォロー・いいね、公式との再生位置同期には対応していません。
購入・加入が必要な場合は公式ページで手続きしてください。
このアプリが視聴権限を付与することはありません。

確認した範囲と残る制限は[検証状況](docs/VALIDATION.md)にまとめています。
