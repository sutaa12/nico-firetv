# 開発と問い合わせ

[README に戻る](../README.md) · [ビルド手順](BUILDING.md)

## 不具合を報告する

[GitHub Issues](https://github.com/sutaa12/nico-firetv/issues)に、次の情報を記載してください。

- Fire TV の機種、Fire OS のバージョン、アプリのバージョンまたはコミット。
- 問題が起きるまでの操作、期待した動作、実際の動作。
- 毎回起きるか、ときどき起きるか。
- デモ／ニコニコのどちらか。ログインが関係する場合は、ログインの有無だけで十分です。
- 画面に出たエラー文。個人情報が含まれる場合は伏せてください。

[データの扱い](PRIVACY.md)を確認し、ログイン情報や端末の個人データを投稿しないでください。
再現に実アカウントが必要でも、パスワードや Cookie を提供する必要はありません。
ニコニコのアカウント自体に関する問い合わせは、公式の窓口を利用してください。

## 変更を提案する

小さな変更は、目的と確認結果を添えて Pull Request を作成してください。
大きな機能変更は、実装する前に Issue で用途や範囲を説明すると、既存の方針との食い違いを減らせます。

主な構成は次のとおりです。

| 場所 | 内容 |
| --- | --- |
| `app/src/main/java/app/nicotv/firetv/ui/` | 一覧、設定、再生画面とリモコン操作 |
| `app/src/main/java/app/nicotv/firetv/data/` | ニコニコ連携、デモ、端末内保存 |
| `app/src/main/java/app/nicotv/firetv/comments/` | コメントの取得、保持、描画の配置 |
| `app/src/test/` | 自動テスト |
| `design/icon/` | アイコンとバナーの制作元 |

## 確認する

JDK 17 と Android SDK を用意して実行します。
Windows では `./gradlew` を `.\gradlew.bat` に読み替えてください。

```sh
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

自動テストの成功だけでは、実際の Fire TV の操作、長時間再生、ニコニコのログインや会員向け機能まで確認したことにはなりません。
変更した動作について、実際に確認した端末・条件と、未確認の条件を区別して記載してください。

## Git に含めないもの

`.gitignore` は公開するソース・文書を限定しています。
ビルド出力、端末固有の設定、作業ログ、端末から取り出したデータ、署名鍵、認証情報は含めません。
新しいトップレベルのフォルダを追加する場合は、必要に応じて `.gitignore` も更新してください。
公開前に追加対象の差分を確認し、無視されたファイルを強制追加しないでください。

提供する変更には、[MIT License](../LICENSE)と両立する権利が必要です。
第三者のコードや素材を追加する場合は、出典とライセンスを保ち、[第三者の権利表記](../THIRD_PARTY_NOTICES.md)も更新してください。
