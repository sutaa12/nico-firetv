# データの扱い

[README に戻る](../README.md) · [使い方](USER_GUIDE.md)

## ログイン情報

ログイン時は、アプリ内の WebView でニコニコ公式のログインページを表示します。
パスワードや二段階認証コードはそのページに入力します。
アプリ独自のパスワード収集・保存処理はありません。
ログイン後は、WebView が管理する Cookie を使ってニコニコへ通信します。
Cookie はログイン状態を再利用できる重要な情報なので、他の人に渡したり、GitHub に貼り付けたりしないでください。

「設定 → アカウント → ログアウト」で Cookie を削除します。
ログアウトしても、端末内の各アカウントの履歴やお気に入りは消えません。

## 端末に保存するもの

| データ | 用途・扱い |
| --- | --- |
| Cookie | ニコニコへのログイン状態を維持する |
| 視聴履歴・再開位置・視聴した区間 | 続きから再開し、端末内の視聴状態を表示する |
| 検索履歴・お気に入り・NG | 次回の検索や表示設定に使う |
| アカウントの識別情報 | 履歴などを取得元・アカウントごとに分ける |
| コメント・動画情報・縮小画像などのキャッシュ | 次回の表示を速くし、再取得を減らす |

履歴・お気に入りなどは、アプリ専用の保存領域に記録します。
アプリ内で個別の暗号化やロック機能は設けていません。
共有端末では、他の利用者によるアプリ操作にも注意してください。
OS のバックアップ・移行・開発用アクセスを通じた取扱いは端末の設定にも依存するため、「端末の外へ絶対に出ない」とは保証しません。

取得し直せるキャッシュには容量上限があります。
一方、視聴履歴やお気に入りなどの利用者データは、容量を減らすために古いものを自動で捨てる設計ではありません。
長く使うと増えるため、端末の空き容量を確認し、不要なデータは設定から消去してください。
アプリ全体の保存容量に一律の上限があるわけではありません。

## 通信先

ニコニコを選んでいるときは、ニコニコのログイン・API・動画・画像・コメント配信先へ通信します。
再生や検索などの操作に伴い、IP アドレス、リクエスト内容、ログイン用 Cookie などを各サービスが受け取ります。
公式ページを WebView で開く場合は、そのページが読み込む外部サービスへの通信もあり得ます。

デモモードでも、test-videos.co.uk、Google の ExoPlayer テスト素材配信先、Apple のサンプル配信先から動画を取得します。
このプロジェクト独自の利用状況解析やクラッシュ収集サーバーへの送信処理はありません。
ただし、ニコニコや動画配信元での記録を止めるものではありません。

## データを消す

「設定 → 保存とデータ」から操作します。

| 操作 | 対象 |
| --- | --- |
| 視聴履歴を消す | 現在の取得元・アカウントの端末内履歴。公式の履歴は変わりません |
| 検索履歴を消す | 現在の取得元・アカウントの端末内検索履歴 |
| コメントの保存を消す | アプリが保存したコメントのキャッシュ |
| 動画情報の保存を消す | 動画情報・シリーズ・一覧とシーク用の縮小画像のキャッシュ |
| すべて初期化 | 全アカウントの設定・履歴・NG・お気に入り。ログイン Cookie と別保存のキャッシュは対象外です |

保存をオフにする設定は、すでに保存したデータの消去とは別です。
Cookie は「設定 → アカウント → ログアウト」で消してください。
端末を譲るなど、アプリのデータをすべて消したい場合は、Fire TV 本体のアプリ管理から NicoTV のデータを消去してください。
この操作は元に戻せません。

## 不具合を報告するとき

GitHub の Issue や添付画像は公開されます。
ログには動画 ID、利用した API、応答の一部などが含まれることがあります。
全文をそのまま載せず、問題の説明に必要な範囲に絞ってください。

パスワード、認証コード、Cookie、認証ヘッダー、期限付きの再生 URL、メールアドレス、氏名、私的なマイリストや視聴履歴、端末の IP アドレスを取り除いてから共有してください。
