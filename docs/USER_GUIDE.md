# 使い方

[README に戻る](../README.md) · [インストール](BUILDING.md) · [データの扱い](PRIVACY.md)

## 最初に操作を試す

1. Fire TV で「NicoTV」を起動します。
2. 左メニューの「設定」を開き、「データの取得元」を「デモ」にします。
3. ホームに戻り、サンプル動画を選んで再生します。
4. 操作を確認できたら、取得元を「ニコニコ」に戻します。

デモはサンプル動画と疑似コメントを使います。
ニコニコのアカウントは不要ですが、動画の配信元への通信は発生します。

## リモコンの基本操作

| ボタン | 一覧・メニュー | 動画の再生中（操作バーを閉じているとき） |
| --- | --- | --- |
| 方向キー | 項目を選ぶ | 左右で再生位置を選ぶ、上でコメント設定、下で操作バー |
| 決定 | 選んだ項目を開く | 操作バーを開く |
| 戻る | 前の画面へ戻る | パネルや操作バーを閉じ、さらに戻ると再生を終了 |
| 再生／一時停止 | — | 再生と一時停止を切り替える |
| 早送り／巻戻し | — | 再生位置を選ぶ |
| メニュー（≡） | 対応する動画カードで追加操作 | 「その他」を開く |

一覧の動画カードでは、決定の長押しでも追加操作を開けます。
機種によってボタンの有無や表記が異なります。

再生位置を選んでいる間は、左右で移動し、決定で確定します。
上下で移動幅を変えられます。
戻るを押すと、位置の変更を取り消します。
Fire TV のホームに移動すると再生は一時停止します。

## 動画を探す・続けて見る

- **ランキング**：ジャンルや期間を選んで探します。
- **検索**：キーワードやタグから探します。検索結果はサービスの更新タイミングにより、最新の投稿をすぐに含まない場合があります。
- **詳細画面**：説明、タグ、投稿者、所属するシリーズを確認できます。
- **ライブラリ**：この端末の履歴やお気に入り、自分のマイリストを開きます。
- **視聴履歴**：ログイン中のニコニコアカウントの履歴を読み込みます。端末内の再開位置とは別の情報です。

シリーズやマイリストの「このページから連続再生」は、今表示しているページの先頭から始まります。
途中の動画から始めたいときは、その動画の追加操作から再生を選びます。
「設定 → 再生」で自動次話や次の話までの待ち時間を変えられます。
視聴できない動画に到達すると、案内を表示して停止します。

## ログインする

1. 「設定 → アカウント → 公式画面でログイン」を開きます。
2. 方向キーで画面の矢印を動かし、決定で入力欄やボタンを押します。
3. 公式画面に従ってログインし、必要なら二段階認証を完了します。
4. アプリに戻ったら、設定のアカウント名を確認します。

画面の端で方向キーを押し続けるとスクロールします。
早送り・巻戻しでは大きくスクロールできます。
戻るはキーボードを閉じる、前のページに戻る、ログインを中止する操作です。

ログインできない場合は「状態を再確認」を試してください。
それでも確認できなければ、公式サイトでログインできるか確認してからやり直します。
ログインしただけで、購入・加入が必要な作品を視聴できるようにはなりません。

## コメントを調整する

再生中に上を押すか、操作バーの「コメント」を開きます。
次回からの初期値は「設定」のコメント設定で変更できます。

| 設定 | 内容 |
| --- | --- |
| オフ／通常／増量 | コメントを隠す、通常分を見る、過去の投稿分も取得する |
| 増量の取得量 | 過去コメントの取得目標。存在するログや会員条件により、目標まで取れない場合があります |
| 画面の密度 | 同時に表示する量。取得量とは別です |
| 読みやすさ優先／弾幕優先 | 重なりを抑えるか、表示量を優先するかを選ぶ |
| 文字の大きさ・不透明度・下端の余白 | 読みやすさや字幕との重なりを調整する |
| コメントの時点 | 選んだ時点までに投稿されたコメントを表示する。利用条件により過去ログを取得できない場合があります |

画面が重いときは、密度を下げるか「通常」に戻してください。
表示される fps の目安は特定条件での参考値で、利用する端末での速度を保証しません。

見たくないコメントは「その他 → コメント一覧」から選んで NG に登録できます。
解除は「設定 → NG」から行います。
NG はこのアプリ内だけに適用され、公式の NG 設定とは同期しません。

## 履歴とお気に入り

端末内の再開位置やお気に入りは、取得元・ニコニコアカウントごとに分かれています。
端末内の履歴を消しても、ニコニコ公式の履歴は消えません。
詳しい消去手順は[データの扱い](PRIVACY.md)を参照してください。

旧版を使っていた場合、「設定 → アカウント」に「旧形式の履歴を引き継ぐ」が表示されることがあります。
以前は表示名を使って保存していたため、自分の履歴であると確認できる場合だけ引き継いでください。
元の履歴は残ります。

## 困ったとき

| 症状 | 試すこと |
| --- | --- |
| 一覧が出ない・更新されない | 通信状態を確認して更新します。サービス側の障害や仕様変更でも取得できなくなります |
| ログインしたのに再生できない | アカウントの「状態を再確認」、動画の「権限を再確認」を試し、公式サイトで視聴できる作品か確認します |
| 映像が止まりやすい | 「設定 → 再生 → 画質」を「回線に合わせる」にします |
| コメントで動作が重い | 密度や増量の取得量を下げます。コメントをオフにして原因を切り分けることもできます |
| 再開位置が残らない | 履歴の保存設定と空き容量を確認します。保存失敗の表示がある場合は、空き容量を確保して再試行します |
| 動画情報が古い | 更新を試します。必要なら「設定 → 保存とデータ」で動画情報の保存を消し、取得し直します |

解消しない場合は[不具合の報告方法](CONTRIBUTING.md)を参照してください。
アカウント名、メールアドレス、ログイン画面、Cookie、視聴履歴が写った画像をそのまま公開しないでください。
