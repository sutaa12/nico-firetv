## 2026-09-26 の公開時点

アプリのバージョンは 0.1.3 です。
公開対象の Git ファイルだけを別の作業場所に展開し、既存の `local.properties` やビルド出力を使わずに確認しました。
依存ライブラリの取得キャッシュは利用しています。

環境は macOS、JDK 17、Android SDK Platform 35、Gradle 8.11.1 です。

| 確認項目 | 結果 |
| --- | --- |
| 単体テスト | 59件成功、失敗・スキップなし |
| Android Lint | エラー0件、警告21件、情報3件 |
| debug APK | ビルド成功・署名の検証成功 |
| release APK | ビルド成功・未署名で出力されることを確認 |
| インストール用スクリプト | 模擬環境で11ケース成功。実端末へのインストールはこの確認では行っていません |
| 公開対象の確認 | 認証情報・秘密鍵・個人用パスなどを検索し、候補を確認。作業記録・端末データ・ビルド出力は除外 |
| Gradle Wrapper | 公式チェックサムと照合 |

単体テストには、アカウントごとの分離、保存失敗、キャッシュの容量・有効期限、コメント取得の上限、連続再生のページ切替などの回帰確認を含みます。

同じアプリコードについて、Android TV API 31 のエミュレータで、デモ動画の再生・一時停止・再開・ホーム移動時の一時停止を確認しています。
今回の公開準備では、この結果を再利用しました。
